# 🚀 Customer Categorizer

An AI-powered Customer Categorization System that predicts customer categories using Machine Learning. The application provides an easy-to-use web interface for entering customer details and receiving instant predictions.

🌐 **Live Demo:** https://customercategorizer-1-2.onrender.com

---

## 📌 Features

- 🤖 Machine Learning-based customer categorization
- 🌐 Interactive web interface
- ⚡ Fast prediction results
- 📊 User-friendly input form
- 🔍 Data preprocessing and prediction pipeline
- ☁️ Deployed on Render

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/vignesh9596/customercategorizer_1.git
```

### Move into the project folder

```bash
cd customercategorizer_1
```

### Create a virtual environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux/Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

or

```bash
uvicorn app:app --reload
```

The application will be available at

```
http://localhost:8000
```
